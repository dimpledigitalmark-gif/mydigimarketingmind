# DigitalBoost — Digital Marketing Agency Website

A responsive static website built with HTML and CSS. No build tools or paid hosting are required.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout

## Customize before publishing
1. Replace `DigitalBoost` with your agency name.
2. Update the email link `hello@youragency.com` in `index.html`.
3. Edit the services, copy, and footer to match your real business.
4. The sample analytics visual is illustrative, not a real client result.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `digital-marketing-website`.
2. Upload `index.html`, `style.css`, and this README to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will show your public website URL on the Pages settings screen.

This is a static HTML/CSS site. The email CTA opens the visitor's email app; a working contact form would require a separate form service or backend.
